# 📊 Power BI Dashboard Portfolio

## Project Overview

Welcome to my **Power BI Dashboard Portfolio!**

This project showcases a collection of five interactive Power BI dashboards designed to analyze different datasets and transform raw data into meaningful business insights.

The portfolio includes a dedicated home page with bookmark-based navigation, allowing users to easily explore each dashboard.

## 🎯 Project Objectives

- Develop interactive and visually appealing dashboards.
- Analyze datasets to identify meaningful insights and trends.
- Create KPI cards and interactive visualizations.
- Use slicers and filters for dynamic data exploration.
- Present data-driven insights through effective storytelling.

## 📁 Dashboard Collection

### 1. Amazon Sales Analysis
- Sales Performance by Category
- Top 10 Best-Selling Products
- Monthly Sales Trend Analysis
- Sales Performance by Region
- Interactive filters for Ship Mode, Category, Region and Segment.

### 2. Impact of COVID-19 on Students
- Distribution of Online Learning Methods
- Online Learning Experience by Residence
- Student Stress Management Activities
- Student Lifestyle Analysis by Age Group
- Interactive filters for Age Group, Region and Online Learning Experience.

### 3. Movie Insights & Analysis
- Movie Distribution by Genre
- Distribution of Movie Ratings
- Year-wise Movie Release Analysis
- Top 8 Highest-Rated Movies
- Interactive filters for Genre, Release Month, Movie Rating and Original Language.

### 4. Online Store Performance Analysis
- Profit vs Target Analysis
- Monthly Revenue Trend Analysis
- Top 8 Customers by Revenue
- Sales Performance by Category
- Interactive filters for Category, Order Month, City, Payment Mode and State.

### 5. HR Analytics & Employee Attrition Analysis
- Attrition Analysis by Job Role
- Work-Life Balance vs Employee Attrition
- Employee Attrition by Department
- Average Monthly Income by Department
- Interactive filters for Department, Gender, Job Role, Business Travel, Overtime and Marital Status.

## 🛠️ Tools & Technologies
